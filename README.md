## Descripción
Análisis de datos de ventas de 4 tiendas para identificar cuál tiene 
el menor rendimiento y recomendarle al Sr. Juan cuál vender.

## Tecnologías utilizadas
- Python 3
- Google Colab
- Pandas
- Matplotlib
- Folium

## Análisis realizados
1. Facturación total por tienda
2. Categorías de productos más vendidas
3. Calificación promedio de clientes
4. Productos más y menos vendidos
5. Costo de envío promedio
6. Análisis geográfico de ventas (EXTRA)

## Conclusión
Después de analizar las 4 tiendas en 5 dimensiones, se recomienda 
al Sr. Juan **vender la Tienda 4**, ya que presenta:
- La menor facturación total: $1,038,375,700
- El menor volumen en categorías clave
- A pesar de tener el menor costo de envío, no logra 
  convertir esa ventaja en mayores ingresos
